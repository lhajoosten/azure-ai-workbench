## Evidence rules

Use implementation statuses `not started`, `in progress`, or `verified`. Use learning statuses `not assessed`, `practiced with help`, `demonstrated`, or `revisit`. A delegated implementation can be verified while its learning status remains not assessed.

Record observations, not private document content, credentials, account identifiers, or raw cloud logs. Use sanitized examples and repository-relative evidence paths.
